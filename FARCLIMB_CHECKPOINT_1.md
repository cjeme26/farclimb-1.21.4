# FarClimb — Checkpoint 1

This checkpoint adds one registered item:

- `farclimb:climbing_axe`
- Display name: **Climbing Axe**
- Temporary appearance: vanilla iron pickaxe
- Creative location: Tools tab
- Stack size: 1
- Durability: 500

It also removes the unused example mixins generated by the Fabric template.

## Test

Run:

```bash
./gradlew runClient
```

Then use:

```mcfunction
/give @s farclimb:climbing_axe 2
```

Success means the game launches and gives you two items named **Climbing Axe**.

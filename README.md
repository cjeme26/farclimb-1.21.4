## FarClimb
FarClimb is a climbing mod that lets you scale cliffs, mountains, and other vertical surfaces using a pair of climbing axes. Instead of relying on ladders or vines, you can freely climb walls, hang from a single axe, and pull yourself over ledges.

The core climbing mechanics are now playable, but the mod is still in active development.

#### Download and installation
Official downloads are available only through CurseForge and Modrinth. 
GitHub is used for source code and development.
Development files and source code on GitHub may be incomplete, unstable, or changed without notice. 

#### Requirements
Minecraft 1.21.4, Fabric Loader and Fabric API

#### What's included?
Climb walls using independent left and right climbing axes.
Move up, down, and sideways while attached to a surface.
Hang from a single axe and sway before reattaching.
First-person climbing axe animations.
Third-person climbing animations.
Camera movement while climbing.
Pull yourself over the top of ledges.
A dedicated FarClimb Creative Mode tab.
A craftable Climbing Axe.

#### Controls
Left click: use the visible left axe
Right click: use the visible right axe
W: climb up
S: climb down
A/D: move sideways
Both axes must be attached to climb. One attached axe lets the player hang and sway.
Climbing towards the top of a block will pull you over.

#### Known alpha limitations
The temporary Climbing Axe uses the vanilla iron pickaxe model.
Third-person planted-axe positioning is still being refined.
Some player skins with outer layers may render incorrectly while climbing.
Multiplayer hasn't been tested yet.
Recipes, animations, and gameplay balance are all subject to change throughout the alpha.
